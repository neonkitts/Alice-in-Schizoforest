# Release 1.7.0 — единое оформление

Общие изображения Windows/WebGL: ui_window, ui_button, ui_card, ui_plaque, ui_ring, ui_inventory, ui_attack, ui_pause. Исходники и происхождение: Assets/ArtSource/UI-ASSETS.md.

Изменения:
- Резные окна, карточки и кнопки заменяют старую тонкую рамку.
- Две одинаковые карточки инвентаря; названия, изображения и описания центрированы.
- Чёрная сплошная обводка букв, подбор размера длинных надписей на кнопках.
- Готовые значки сумки, атаки и паузы в Windows и на сайте; атака использует изображение анализов.
- HUD привязан к безопасным краям экрана, масштаб не зависит от времени и позиции на карте.
- Полноэкранные затемнение, загрузочный переход и рассвет.
- Камера поднимается по замку; деревья сохранений опираются на поверхность камней.
- Один приоритетный слой сообщений; обучение подавляет обычные уведомления, трофей подавляет сообщения о рывке и имя врага.
- Имя врага: «Демон заживления тату».
- Загрузочная надпись сайта перенесена наверх и не перекрывает приглашение на постере.
- URL загрузчика, данных и WASM содержат версию 1.7.0.

Веб-браузерная визуальная проверка недоступна: встроенный браузер отказал из-за недоступной проверки политики администратора. Проверки сенсорных обработчиков выполняются отдельно; физический телефон не проверен.

Проверки: Windows Build Succeeded; 141302 проверки генерации/механик, mobile checks (1000 terrain, 7 repeat jumps, 8 sprites), 7 persistence checks. Проверены снимки финального окна, инвентаря и диалога доктора. По уточнению пользователя подпись у значка инвентаря убрана; экранная атака только на сенсорных устройствах.

1.7.1: загрузка внизу; единый visualViewport для CSS и render buffer; DPR ограничен 2; отключён конкурирующий Unity matchWebGLToCanvasSize; WebGL safe area соответствует полному canvas. DOM-тест проверяет скрытие адресной строки (350→390px), DPR=3 и размеры буфера. Проверка на физическом телефоне не выполнена.
